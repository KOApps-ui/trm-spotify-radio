# TürkRockMetal Spotify Radyo

TürkRockMetal topluluğunun resmî Spotify listelerini tarayıcıda çalan statik sayfa.

- 30 saniyelik önizlemeler
- Tam listeler için Spotify embed oynatıcısı
- Rastgele şarkı / rastgele liste
- Bilgisayar kapalıyken de GitHub Pages üzerinden erişilebilir

Sayfa, `TürkRockMetal-Spotify` botunun ürettiği `spotify_radyo.html` dosyasından alınır.
Liste verileri Spotify'ın herkese açık embed sayfalarından okunur; Spotify hesabı veya API anahtarı gerekmez.
